Forge 1.3.0

Redesigned dark studio with Setup, Detail and Framing panels, synchronized before/after preview, zoom, sample positioning and reduced-motion support.
Smart Auto inspects source specs and sample brightness. Save your own presets and export several destinations in one batch.
Optional local GFPGAN face blending and Real-ESRGAN neural denoising use the bundled CPU runtime. Preview first: models can change faces or smooth detail, and CPU processing can take substantial time.
Portrait 9:16 crop supports center, manual position and smoothed largest-frontal-face following. Stabilization compensates small camera shake with a visible border-crop setting.
Scene-cut and conservative fast-motion protection replace risky interpolated frames with source-frame holds. Compression preview simulates a heavily compressed upload; it does not predict platform output.
Pause social/master exports at validated five-second checkpoints, then resume after reopening Forge. The current unfinished section restarts. Lossless remux can be cancelled but does not use checkpoints.
Fixed tiny-video GPU encoding failures, the export lock after clearing a sample, and shared-source ownership for multiple export destinations.
The larger installer includes the local AI runtime and models. No external Python installation is required. Existing older updaters that stall can be bypassed by installing this setup executable once.
