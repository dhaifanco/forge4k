Forge 1.3.1 — core processing speed

Face restoration and neural denoising now use DirectML GPU acceleration with the same official FP32 weights. CPU fallback handles unsupported devices or driver failures; CPU mode remains available.
Measured restoration stage for eight 256x256 face frames, including startup: 35.6 seconds on the previous CPU path versus 8.6 seconds on an RTX 3060 GPU. This is not a full-length 4K export benchmark.
Denoise uses wider tile overlap to prevent interior seams. Faster lossless PNG writing reduces intermediate processing overhead, and source-size tile assembly avoids a full 4x frame allocation.
The standalone runtime excludes training libraries and duplicate model weights. Python, models and required licenses remain bundled; no external installation is needed.
Regression, API, signed-update, checkpoint, GPU/CPU numerical and actual restoration-export tests pass.
No new editing features. Existing project data and update controls remain compatible. Models can still smooth texture or change face details. Forge does not claim Topaz parity or guarantee quality after social-platform recompression.
