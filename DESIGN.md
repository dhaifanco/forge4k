# Forge studio direction

User choice: dark video studio, tidy layout, blue accent. Apply antislop during design.

Audience: short-form video creators preparing TikTok and Instagram uploads locally.
Energy 2 / Rhythm 2 / Motion 2. The user requested a full friendly studio redesign with motion in September 2026.

The video monitor is the focal point. Export settings sit to its right; source files and queue sit below. A narrow navigation rail separates editing from analysis, history, preferences and app updates.

Charcoal surfaces avoid distracting from source footage. Blue marks selection and the primary export action. Green, amber and red communicate actual operation status only. Segoe UI uses the native Windows reading rhythm; tabular numbers are reserved for media measurements. Frame-corner marks tie import and preview to the video task. Borders group controls without decorating every surface. Short state transitions show hover/selection; no ambient animation.

Use the existing Forge name as a text wordmark, without creating new logo art. Keep theme support to the user-requested dark studio. All controls need keyboard focus, meaningful empty/loading/error states, and readable contrast. Stack the inspector below the monitor at narrow widths.

Version 1.2 keeps enhancement in an expandable section of the export inspector to preserve the normal import/export workflow. Explicit model labels distinguish AI detail and interpolation from conventional noise filtering. A secondary sample-export action reduces the cost of checking altered faces and motion; its playable result stays in the existing queue rather than introducing a new navigation destination.

The new studio groups Setup, Detail and Framing in an inspector beside a comparison monitor. The four workflow markers explain the path from import to export. Saved looks and multiple destinations belong to Setup. A film-frame motif marks the empty import target; it is interface geometry, not a new logo. Blue identifies selection and export, while progress retains status colors. Panel changes use a brief 5px transition; completed jobs briefly settle into place and progress eases between updates. Motion communicates state and stops under reduced-motion preferences. The shared rail, headers, forms, history and update panels use the same revised surfaces, typography and spacing across every page.
